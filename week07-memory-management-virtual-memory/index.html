Memory Management & Virtual Memory

Explore how operating systems bridge the chasm between raw physical hardware addressing and isolated virtual memory abstractions. Learn the mathematics and hardware mechanics of address translation, dynamic partitioning, paging tables, and Translation Lookaside Buffers (TLBs).

  • Internal vs. external memory fragmentation
