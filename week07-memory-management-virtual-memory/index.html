Curriculum Track • Week 07

Memory Management & Virtual Memory

Explore how operating systems bridge the chasm between raw physical hardware addressing and isolated virtual memory abstractions. Learn the mathematics and hardware mechanics of address translation, dynamic partitioning, paging tables, and Translation Lookaside Buffers (TLBs).

📚 What You Will Learn

1. Hardware Relocation & Protection

Understand the transition from monoprogrammed bare metal to multiprogramming using base and limit registers, dynamic relocation, and swapping mechanisms.

2. Dynamic Memory Partitioning

Master contiguous free-space management algorithms (First-Fit, Best-Fit, Worst-Fit) and buddy-allocator power-of-two coalescing strategies.

3. Virtual Paging & MMU Address Translation

Deconstruct virtual addresses into Page Numbers ($p$) and Offsets ($d$), navigate multi-level hierarchical page tables, and evaluate PTE protection bit flags.

4. TLB Caching & Memory Access Latency

Calculate Effective Memory Access Times (EMAT) and analyze associative hardware TLB hit/miss penalties and inverted page table hashing schemes.

✅ What You Should Do

  • 📖 1. Core Textbook Readings

    Read Tanenbaum & Bos (Modern Operating Systems) Chapter 3 (Memory Management) and OSTEP Chapters 13–16 (Address Spaces & Paging).

  • 💻 2. Complete Module Walkthroughs

    Progress through Modules 01 to 04 sequentially, tracing address translation mathematics and paging bitfields.

  • 🤖 3. Lab: Allocator Simulation

    Implement a free-memory list tracker in Python or C to compare allocation fragmentation under First-Fit and Best-Fit policies.

  • 📝 4. Self-Assessment Exercises

    Solve manual virtual-to-physical address translation problems and compute multi-level page table memory footprints.
