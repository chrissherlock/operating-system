04. Multi-Level Feedback Queues (MLFQ)

In real-world operating systems, the kernel rarely knows how long a job will run in advance. To solve this, Fernando Corbató pioneered the Multi-Level Feedback Queue (MLFQ), a scheduling architecture that learns job behavior dynamically based on past execution history.

Core MLFQ Rules

  • Rule 1: If Priority(A) > Priority(B), A runs (B does not).
  • Rule 2: If Priority(A) == Priority(B), A & B run in Round Robin.
  • Rule 3: When a job enters the system, it is placed at the highest priority queue.
  • Rule 4: If a job uses up its time allotment while running, its priority is reduced (moved down one queue).
  • Rule 5: After some time period S, move all jobs in the system to the topmost queue (preventing starvation).
