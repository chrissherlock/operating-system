Week 10: File Management & Storage Systems

Having examined process scheduling, synchronization, and volatile memory virtualization, we confront the challenge of persistence. We analyze how the kernel virtualizes non-volatile physical storage blocks into structured, named byte streams: File Abstractions, Directory Trees, Inode Allocation Schemes, and Crash Consistency via Journaling.

📚 What You Will Learn
  • The fundamental File Abstraction: unformatted byte streams vs. record sequences and database key trees.
  • POSIX file descriptors, open file description tables, and VFS inode table interaction across fork() and dup().
  • Directory topologies, recursive path resolution, hard links vs. symbolic links, and link count invariants.
  • On-disk allocation structures: Contiguous allocation, File Allocation Tables (FAT), and UNIX Inode multi-level block pointers.
  • Crash consistency, Write-Ahead Logging (WAL), journaling modes (data vs. metadata), and filesystem recovery (fsck).
✅ What You Should Do
  • Read Tanenbaum & Bos Chapter 4 (File Systems) and OSTEP Chapters 39–42.
  • Work through Modules 01 to 04 sequentially, tracing block pointer indirection and inode structures.
  • Complete Theory Tutorial 10 (Inode Maximum File Size Calculations & Indirect Blocks).
  • Complete Practical Tutorial 10 (Implementing a Simple File System Directory Parser in C).
  • Prepare for Quiz 5 (covering Virtual Memory, Paging, and File System Implementations).
