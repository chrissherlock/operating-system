Tanenbaum Chapter 4.1: The File Abstraction, Attributes, Operations, and POSIX System Calls.

1. Architectural Foundations: The File Abstraction

Just as the operating system abstracts physical RAM into virtual address spaces and CPU cores into processes, it abstracts raw disk hardware (cylinders, sectors, and magnetic heads) into files. A file is an abstract logical unit of persistent information created by processes.

Core Concepts Covered in Tanenbaum 4.1:
  • File Naming & Sensitivity: Rules governing valid strings (up to 255+ characters) and whether the OS distinguishes uppercase and lowercase (UNIX vs. Windows).
  • File Structure Models: Unstructured byte sequences (UNIX/Windows), record sequences (mainframe batch systems), and key-indexed tree structures.
  • File Types: Regular files (ASCII/binary), directories, and device abstractions (character and block special files).
  • Access Modes: Sequential access (reading byte-by-byte from the beginning) vs. random access (using explicit offset seeking).
  • File Attributes (Metadata): Protection permissions, ownership (UID/GID), sizes, and timestamps (creation, access, modification).
