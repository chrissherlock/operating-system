Module 03 • COSC240

Deadlock Avoidance & Banker's Algorithm

Explore deadlock avoidance strategies through Edsger Dijkstra's Banker's Algorithm. Evaluate safety state invariants, resource request vectors, and matrix inequality tests.

1. Deadlock Prevention vs. Avoidance

While deadlock prevention restricts system design by negating one of the four Coffman conditions statically, deadlock avoidance allows the system to accept resource requests dynamically while inspecting future allocation states to ensure the system never slips into an unsafe region.

2. Dijkstra's Banker's Algorithm

The Banker's Algorithm evaluates resource allocation requests by simulating whether granting a request leaves the system in a safe state (where a safe execution sequence $\langle P_0, P_1, \dots, P_n \rangle$ exists).

Safety Matrix Inequality Test:

$$ \text{Need}_{i} = \text{Max}_{i} - \text{Allocation}_{i} $$ $$ \text{Find process } P_i \text{ such that Finish}[i] == \text{false } \land \text{Need}_{i} \le \text{Available} $$
