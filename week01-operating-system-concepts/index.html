Operating System Concepts & History

Exploring operating system abstractions, the dual role of the OS as an extended machine and resource manager, and the chronological evolution of computing generations.

1.1 What Is An Operating System?

At its core, a computer system consists of hardware (processors, memory, disks, keyboard, display, network interfaces) and software. Writing application programs directly on top of bare metal hardware is exceedingly complex. Programmers would need to understand disk sector geometry, bus arbitration timing, and voltage levels for every peripheral device.

To bridge this gap, modern computer systems include a layer of software called the operating system (OS). The operating system performs two fundamentally distinct functions:

1. The Operating System as an Extended Machine

The architecture (instruction set, memory organization, I/O instructions) of raw computer hardware is primitive and cumbersome to program. For example, reading a block from a disk requires commanding the disk controller, checking error correction codes, managing rotational delay, and handling head positioning tracks.

The operating system abstracts this raw hardware ugliness away, presenting the programmer with a clean, elegant, and easy-to-use virtual machine—an extended machine. Instead of managing disk sectors, application software interacts with logical files organized in hierarchical directories. Instead of dealing with raw network packets and Ethernet frames, applications open TCP sockets. The OS translates these high-level system calls into low-level hardware control sequences.

2. The Operating System as a Resource Manager

Modern computers support multiprogramming, where multiple programs execute concurrently, competing for shared physical resources: CPU execution time, main memory space, storage capacity, and bandwidth across input/output devices.

As a resource manager, the operating system controls the allocation of these resources efficiently and fairly. Resource multiplexing occurs in two dimensions:

  • Time Multiplexing: The CPU switches rapidly between multiple running processes or threads. Each program gets a small time slice on the processor, creating the illusion that multiple programs run simultaneously.
  • Space Multiplexing: Main memory and disk storage are partitioned among multiple active programs, ensuring that Program A cannot overwrite or inspect the memory space of Program B without explicit permission.

1.2 History Of Operating Systems

Operating systems have evolved in parallel with computer hardware across five distinct generations, driven by breakthroughs in electronic components, programming languages, and miniaturization.

1. The First Generation (1945–1955): Vacuum Tubes and Plugboards

Following electronic breakthroughs during World War II, computers were built using vacuum tubes. These machines were massive, unreliable, and immensely expensive. A single computer filled an entire room and was operated entirely by small teams of engineers and mathematicians.

There were no operating systems. Programs were written entirely in machine language or wired manually onto plugboards. Every job required setting physical switches and plugging cables into patch panels.

2. The Second Generation (1955–1965): Transistors and Batch Systems

The invention of the transistor in the 1950s made computers reliable enough to manufacture and sell commercially. This era introduced batch systems to eliminate human operator idle time. Users wrote programs on punch cards, carried their card decks to the computer center, and handed them to operators.

Operators grouped similar jobs (e.g., all FORTRAN jobs) into a batch, loaded them onto magnetic tape, and ran them sequentially using early batch monitors like IBSYS.

3. The Third Generation (1965–1980): ICs and Multiprogramming

In the mid-1960s, manufacturers replaced discrete transistors with Integrated Circuits (ICs), giving birth to mainstream mainframe computers (such as the IBM System/360).

The defining architectural breakthrough of this era was multiprogramming. When a job paused to wait for slow I/O operations (like reading a card or printing output), the CPU did not sit idle; the operating system switched memory contexts to run another loaded program. This era also gave birth to timesharing systems (e.g., CTSS, Multics, and early UNIX) allowing multiple interactive terminal users to access the computer simultaneously.

4. The Fourth Generation (1980–Present): Personal Computers

The advent of Large Scale Integration (LSI) placed thousands, and later millions, of transistors on a single silicon chip. Personal computers (PCs) became affordable commodities.

While early microcomputers lacked operating systems (e.g., CP/M and early MS-DOS), graphical user interfaces (GUIs), pioneered at Xerox PARC and popularized by Apple Macintosh and Microsoft Windows, transformed personal computing. Modern multiprocessor and multitasking kernels became standard on desktop and server hardware.

5. The Fifth Generation (1990–Present): Mobile and Ubiquitous Computing

The proliferation of high-speed wireless networking, flash memory, and highly power-efficient system-on-chip (SoC) architectures ushered in the fifth generation: mobile phones, tablets, smart wearables, and Internet of Things (IoT) devices. Modern mobile operating systems (Android, iOS) manage stringent battery constraints, touch interfaces, cellular radios, and hardware sensors.
