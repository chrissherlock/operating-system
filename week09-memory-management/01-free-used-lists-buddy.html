Managing Physical Memory: Free/Used Lists & Buddy Allocator

Tanenbaum Section 3.2: How operating systems track physical RAM allocation using free lists, bitmaps, and the binary buddy algorithm.

1. Tracking Physical Memory: Free Lists & Used Lists

Before virtual memory maps individual pages, the operating system kernel must manage raw physical RAM. How does the kernel know which physical page frames are occupied and which are available?

Historically, operating systems use two primary bookkeeping structures:

  • The Free List: A linked list of unallocated memory blocks or page frames that processes can claim instantly.
  • The Used List: A linked list or table tracking active allocations so the kernel knows who owns what when processes terminate.
Alternative: Bitmaps. A bit array where 0 represents a free frame and 1 represents an allocated frame. While compact, bitmaps require linear scans to find contiguous blocks.
