How Hardware Associativity Actually Operates

Standard RAM is indexed: to find entry i, an address decoder energizes row i. However, the TLB does not work by index; it works by associative content search.

Inside the CPU MMU, every single TLB slot has its own dedicated hardware comparator circuit. When the CPU emits a Virtual Page Number (VPN):

  1. The VPN is broadcast simultaneously across a parallel wire bus to all comparators at the exact same instant.
  2. Each slot compares its stored tag against the incoming VPN.
  3. If a slot matches and its Valid = 1, it pulls a match wire high, immediately outputting its stored Page Frame Number (PFN).
TLB Hit: Output delivered to DRAM address bus in < 1 nanosecond.
TLB Miss: All comparator lines output low → MMU stalls CPU and starts multi-cycle DRAM walk.
