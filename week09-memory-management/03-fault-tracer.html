Classifying Translation Failures

Tanenbaum Section 3.3.4 (Page 203): Tracing execution flow through the hardware MMU and kernel fault handlers.

Not All "Page Faults" Are Created Equal

Whenever the CPU attempts to dereference a virtual address, translation follows a strict hierarchy of decision points. Depending on where the mapping breaks down, the cost and handling mechanism vary radically:

  1. TLB Hit: The address translation exists directly in CPU associative registers. Translated to physical DRAM in < 1 ns without consulting memory.
  2. Soft Miss (Minor Page Fault): The page is already in physical RAM (e.g. shared libraries or a reclaimed standby page), but absent from this thread's PTE or TLB. The kernel simply maps the PTE to the existing DRAM frame. Cost: ~15 instructions, 0 disk I/O.
  3. Hard Miss (Major Page Fault): The page is missing from RAM entirely and resides on swap or an executable file on SSD. The kernel puts the thread to sleep while an asynchronous DMA storage transfer executes. Cost: Millions of clock cycles.
  4. Segmentation Violation (SIGSEGV): The requested address does not correspond to any valid allocated memory region (VMA) in the process address space. The kernel dispatches a termination signal immediately.
