Bit Definitions (Tanenbaum Sec 3.3.1)
BitFull NameRole in Hardware MMU
PresentPresent / Absent1 = Frame in DRAM. 0 = On disk; access triggers a Page Fault.
ProtectionProtection0 = Read-only. 1 = Read & Write allowed.
ReferencedReferencedHardware sets to 1 on read/write. Cleared by OS clock ticks.
ModifiedModified (Dirty)Hardware sets to 1 on write. If 1, page must be saved to disk on eviction.
CachingCaching Disabled1 = Bypasses CPU L1/L2 caches; used for memory-mapped I/O registers.
SupervisorUser / Supervisor0 = Userland accessible. 1 = Kernel/Supervisor mode only.
