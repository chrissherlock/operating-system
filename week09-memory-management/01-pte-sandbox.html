Flag Definitions (Tanenbaum Sec 3.3.1)
Flag Name Hardware MMU Function
P Present/Absent 1 = Page is loaded in physical DRAM. 0 = Page is absent (access causes a Page Fault).
R/W Protection 0 = Read-Only access allowed. 1 = Read and Write allowed.
R Referenced Hardware automatically sets to 1 on read or write. Cleared periodically by clock interrupt.
M Modified (Dirty) Hardware automatically sets to 1 on write. If 1, page must be written to disk on eviction.
PCD Caching Disabled 1 = Bypasses CPU cache. Vital for memory-mapped I/O device registers.
U/S User/Supervisor 0 = Accessible by userland. 1 = Supervisor (kernel mode) access only.
